## App Description:
- This web app opens a social platform for users to create their own account. Currently, it is only allowing users to change their personal description.
- The app includes some basic functions such as: sign in, view personal profile, modify description in 'setting' page, and sign out (which comes back to sign in page).
- It also has an admin page to create new account as the information goes straight into the SQL database named 'socialnet'.
- The functions to connect with other accounts is still in development. Therefore, the 'Profile' page only show the personal profile (though the PHP file handles the query statement 'owner', if it is blank, 'Profile' page display the account's profile).
